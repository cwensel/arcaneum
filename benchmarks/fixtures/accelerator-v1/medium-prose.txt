Arcaneum builds a searchable representation of source code and documents. A useful benchmark must preserve realistic variation: identifiers, punctuation, prose, and repeated concepts all affect tokenization. The scheduler should not infer accelerator safety from the number of strings alone because padding a mixed batch to its longest sequence can dominate memory and runtime. This fixture is intentionally ordinary prose so that future backends can compare the same input without relying on proprietary corpora or a network download.
